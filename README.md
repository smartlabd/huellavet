# Huella Vet

Maqueta navegable de un sistema de gestión para clínicas veterinarias: citas, fichas de mascotas, historia clínica, cobros en dólares con conversión a bolívares a la tasa BCV, inventario, gastos y reportes.

Es una maqueta de demostración: no guarda datos y todas las cifras son de ejemplo.

Archivo único: `index.html`.
